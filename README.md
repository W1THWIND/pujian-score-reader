# 谱间 · PDF 乐谱阅读器

Chrome / Edge Manifest V3 扩展。点击扩展图标打开独立乐谱阅读页，导入本机 PDF，按自己的节奏翻阅乐谱。

## 安装（无需运行开发命令）

本项目的 `extension` 文件夹已包含 PDF.js 渲染依赖，可直接加载。

1. Chrome 地址栏打开 `chrome://extensions`，或 Edge 打开 `edge://extensions`。
2. 开启“开发者模式”，选择“加载已解压的扩展程序”。
3. 选择本项目里的 **extension 文件夹**，不要选整个项目目录。
4. 在浏览器扩展菜单中找到“谱间 · 乐谱阅读器”，点击图标打开阅读器。
5. 导入 PDF，检查自动裁边和节点，点左侧“开始演奏”即可自动开启鼠标左右键翻页并进入纯乐谱视图。右上角开关仍可单独控制鼠标翻页。

更新源码后，在扩展管理页面点“重新加载”，并重新打开阅读器。已有谱子的调整记录会保留；要应用更新后的识别算法，可在节点编辑面板逐页点击“重新识别此页”。

## 使用

- **逐页**：每次前进一张裁边后的 PDF 页面。
- **逐行**：每次前进一个阅读段，显示当前及下一行，支持跨 PDF 页拼接。
- **逐两行**：每次前进两个阅读段；末尾不足两行时显示剩余部分。
- 钢琴左右手的两组五线谱合起来算一行。手动节点决定最终阅读段。
- 阅读区顶部的“衔接参考”开关控制上一行缩略图。逐行和逐两行模式下可开启或关闭；关闭后只显示当前及后续谱行，设置会随此谱保存。逐页模式下此开关不可用。演奏时请先按 Esc 恢复控件再调整。
- 开启右上角鼠标开关后，把鼠标指针停在谱面区域：**左键前进，右键回退**。
- 空格、右方向键、PageDown 前进；左方向键、PageUp 回退。Esc 退出纯乐谱视图，鼠标开关保持原状。键盘翻页在演奏模式下生效，不依赖鼠标开关。
- 点击左侧“开始演奏”后隐藏 Logo 栏、设置侧栏、顶部控制栏、底部按钮、提示浮层和鼠标指针，只显示乐谱。按 Esc 退出演奏后恢复所有控件；底部前后按钮可用于预览。浏览器自身的标签栏和地址栏需使用全屏模式隐藏。
- 防连击默认 350 ms，可在 100–1000 ms 之间调整。长按键盘不会连续翻页。
- 切换到其他标签页后自动退出演奏视图；鼠标开关保持原状。重新导入文件或重开页面时，鼠标开关默认关闭。
- 全屏按钮可扩大谱面。演奏时尝试请求屏幕常亮，是否生效由浏览器决定。

## 调整裁边与节点

退出演奏后，点击“调整裁边与翻页节点”：

- 绿色虚线代表谱行之间的翻页节点，可拖动、添加、删除。
- 金色四边线控制可见区域，灰色部分会隐藏。
- 使用“保留整页”可撤回自动裁边；节点保持不变。
- “重新识别此页”会替换本页裁边和节点，可用“撤销”恢复。
- 可按 Tab 选中边界或节点，用方向键微调。
- “保存并返回”后，可用底部“下一段”预览。关闭编辑面板或按 Esc 也会保存编辑。

原始 PDF 始终不变。PDF、每份谱子的节点、翻页模式、位置和防连击设置保存在此浏览器的本地 IndexedDB 中；重新导入同一文件会恢复设置，重新打开阅读器会恢复最近一份谱子。内容哈希用于区分同名文件。可用“清除此谱的本地记录”删除当前谱子的浏览器副本。

## 识别范围与限制

首版使用图像行投影识别五条平行谱线，按上下两组配对为钢琴谱行。无需联网或 AI 服务，不做音符识别。

自动裁边主要隐藏页边空白、远离谱面的标题及尾部文字；它**不是语义过滤器**，不会自动去除夹在谱中的水印、作者署名或广告。保守边距用于保留指法、速度、力度、踏板等标记，用户仍应逐页检查。

歪斜扫描、线条很淡、单谱表、三谱表、复杂合奏谱或漏检导致的错误配对，都可能需要人工调整。检测不到可靠谱线时保留整页并提示；偶数个谱表也不代表配对必然正确。加密 PDF 需先用已解锁副本。暂不支持重复段自动跳转。

扩展使用自己的阅读器，不接管 Chrome 内置 PDF 查看器或 Zotero 阅读器。鼠标必须位于本阅读器谱面区域，无法在后台全局截获点击。

## 开发命令

```powershell
npm ci
npm run build
npm test
node tests/browser.mjs 'C:\private-scores\reference.pdf'
node tests/extension.mjs 'C:\private-scores\reference.pdf'
```

以上路径是占位示例，请替换成本机测试文件。浏览器测试使用本机已安装的 Chrome / Edge，无需额外下载测试浏览器。当前浏览器回归测试包含私有参考谱的 5 页 / 17 行断言，任意其他谱子不一定通过；更换测试材料时需要更新预期页数和谱行数。核心测试 `npm test` 无需乐谱文件。

源码入口：`extension/reader.mjs`；谱行算法与翻页逻辑：`extension/core.mjs`。`scripts/build.mjs` 将锁定版本的 PDF.js 复制到扩展内部；运行时没有 CDN 依赖。PDF.js 的 Apache-2.0 许可证随包附在 `extension/vendor/PDFJS-LICENSE`。

参考：[PDF.js 官方示例](https://mozilla.github.io/pdf.js/examples/) · [Chrome 扩展 CSP](https://developer.chrome.com/docs/extensions/reference/manifest/content-security-policy)
